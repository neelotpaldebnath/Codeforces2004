## Problem Statement

Each update is given in the form $$$(p, x)$$$, which means the number of sausages of flavor $$$p$$$ in the warehouse is changed to $$$x$$$ (i.e., $$$a_p := x$$$).</p><p>Reyhaneh can perform the following operation on the sausages any number of times (possibly zero): </p><ul> <li> Choose an index $$$1 \leq i \lt n$$$ and an integer $$$1 \leq k \leq 5$$$, then replace $$$a_i$$$ and $$$a_{i+1}$$$ with $$$a_i \oplus (3 \cdot k)$$$ and $$$a_{i+1} \oplus (3 \cdot k)$$$, respectively, where $$$\oplus$$$ denotes the <a href="https://en.wikipedia.org/wiki/Bitwise_operation#XOR">bitwise XOR</a>. </li></ul><p>In SauSaGe City, a sausage flavor is called <span class="tex-font-style-it">All-Meat</span> if its quantity is divisible by $$$3$$$. Three famous sausage critics — Shafi, Shafaghi, and Ghaffari — only like flavors that are All-Meat.</p><p>Before processing any updates, and after each of the $$$q$$$ updates, you need to answer the following question: If Reyhaneh performs an arbitrary number of operations optimally, what is the maximum possible number of sausage flavors that the three critics would like?</p><p><span class="tex-font-style-bf">Note:</span> The operations you perform to find the answer for each state are hypothetical and do not affect the array for subsequent queries. However, the $$$q$$$ inventory updates ($$$a_p := x$$$) are permanent.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 10^4$$$).
