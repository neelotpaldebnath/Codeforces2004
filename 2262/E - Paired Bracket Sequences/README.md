## Problem Statement

<div class="header"><div class="title">E. Paired Bracket Sequences</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p> </p><p>Farmer John is interested in bracket sequences with common pairings.</p><p>A balanced bracket sequence is one in which every opening bracket is matched with a later closing bracket, and no prefix contains more closing brackets than opening brackets.</p><p>For a balanced bracket sequence $$$s$$$, a pairing is a pair of positions $$$(i,j)$$$ with $$$i \lt j$$$ such that $$$s_i$$$ is an opening bracket, $$$s_j$$$ is a closing bracket, and the substring strictly between them is balanced. </p><p>Consider an ordered pair $$$(s,t)$$$ of balanced bracket sequences, where both $$$s$$$ and $$$t$$$ have length $$$2n$$$. A pairing $$$(i,j)$$$ is common to $$$s$$$ and $$$t$$$ if $$$(i,j)$$$ is a pairing in both sequences. For example, the bracket sequences $$$\texttt{(()())}$$$ and $$$\texttt{((()))}$$$ have one common pairing, namely the outer pair $$$(1,6)$$$.</p><p>Two ordered pairs $$$(s,t)$$$ and $$$(s',t')$$$ are considered different if $$$s \ne s'$$$ or $$$t \ne t'$$$.</p><p>For each $$$0 \le k \le n$$$, Farmer John wants to know the number of ordered pairs $$$(s,t)$$$ of balanced bracket sequences of length $$$2n$$$ with exactly $$$k$$$ common pairings. Since these numbers may be large, output them modulo $$$M$$$.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 500$$$). The description of the test cases follows.</p><p>The first line of each testcase will contain two integers, $$$n$$$ and $$$M$$$ ($$$1 \leq n \leq 500$$$, $$$10^8 \leq M \leq 10^9$$$) — half the length of the bracket sequence and the modulo to output the answer in. It is guaranteed that $$$M$$$ is prime.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$500$$$. </p></div><div class="output-specification"><div
