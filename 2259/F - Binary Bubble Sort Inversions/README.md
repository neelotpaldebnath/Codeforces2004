## Problem Statement

<div class="header"><div class="title">F. Binary Bubble Sort Inversions</div><div class="time-limit"><div class="property-title">time limit per test</div>3 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>Define performing a bubble on an array $$$b_1, b_2, \ldots, b_m$$$ to be performing the following action: </p><ul> <li> For each integer $$$i$$$ ($$$1 \leq i  \lt  m$$$) <span class="tex-font-style-bf">in order</span>, if $$$b_i  \gt  b_{i+1}$$$, swap $$$b_i$$$ and $$$b_{i+1}$$$. </li></ul> Define performing a reverse bubble on an array $$$b_1, b_2, \ldots, b_m$$$ to be performing the following action: <ul> <li> For each integer $$$i$$$ ($$$1 \leq i  \lt  m$$$) <span class="tex-font-style-bf">in reverse order</span>, if $$$b_i  \gt  b_{i+1}$$$, swap $$$b_i$$$ and $$$b_{i+1}$$$. </li></ul><p>For example, if we perform a bubble on $$$[1, 1, 0]$$$, we would transform it as follows: $$$[\color{red}{1, 1}, 0] \to [1, \color{red}{1, 0}] \to [1, 0, 1]$$$. If we perform a reverse bubble on $$$[1, 1, 0]$$$, we would transform it as follows: $$$[1, \color{red}{1, 0}] \to[\color{red}{1, 0}, 1] \to [0, 1, 1]$$$.</p><p>You are given an array $$$a_1, a_2, \ldots, a_n$$$ consisting of only <span class="tex-font-style-tt">0</span>s and <span class="tex-font-style-tt">1</span>s and a binary string$$$^{\text{∗}}$$$ $$$s$$$ of length $$$n$$$. For each of the $$$n + 1$$$ states of $$$a$$$ — before any operations have been performed and after each operation — count the number of inversions$$$^{\text{†}}$$$ in $$$a$$$.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$A binary string is a string that only contains <span class="tex-font-style-tt">0</span>s and <span c_j$$$.</p></div></div><div class="input-specification"><div class="section-title">Input</div><p>The first line of each input contains $$$t$$$ ($$$1 \leq t \leq 10^4$$$) — the number of test \ldots, a_n$$$ ($$$0 \leq a_i \leq 1$$$) — the array $$$a$$$.</p><p>The third line of each test case contains $$$s$$$ ($$$s_i \in \{0, 1\}$$$, $$$|s| = n$$$$$$^{\text{∗}}$$$) — the binary string $$$s$$$.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$5 \cdot 10^5$$$.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$$$$|c|$$$ denotes the length of a
