More formally, set $$$a_p := a_p + 1$$$. This operation may only be performed if $$$a_p  \lt  n$$$. </li><li> Operation $$$2$$$: Follow the road from the current barn. More formally, set $$$p := a_p$$$. </li></ul><p>Operation $$$1$$$ changes the array $$$a$$$, but Bessie stays at the same barn. If it is possible, output any valid starting barn and any sequence of operations that makes $$$a=b$$$.</p><p>It can be shown that if a solution exists, then there exists one using at most $$$2n^2$$$ operations.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. This operation may only be used if $$$a_p  \lt  n$$$ at that moment.</p><p>If $$$c_i=2$$$, you perform operation $$$2$$$ and set $$$p:=a_p$$$. </p><p>After performing all $$$o$$$ operations, the array
