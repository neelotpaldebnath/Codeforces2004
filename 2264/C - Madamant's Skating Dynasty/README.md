<div class="header"><div class="title">C. Madamant's Skating Dynasty</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>Madam Madamant is expecting a baby and already planning a skating dynasty in which every parent is a stronger skater than their children.</p><p>Formally, Madamant has $$$n$$$ labeled skaters. Skater $$$v$$$ has an integer rating $$$a_v$$$, and all ratings are pairwise distinct. A possible dynasty is represented by a rooted tree on these skaters.</p><p>Let $$$r$$$ be the root of the tree. For every skater $$$v \ne r$$$, let $$$p_v$$$ be the parent of $$$v$$$. The dynasty is <span class="tex-font-style-it">valid</span> if $$$a_v  \lt  a_{p_v}$$$ for every $$$v \ne r$$$.</p><p>The cost of a valid dynasty is $$$$$$ \sum_{v \ne r} (a_{p_v} - a_v). $$$$$$</p><p>Two dynasties are different if their roots are different or if the parent of at least one skater is different.</p><p>Find the sum of the costs of all valid dynasties Madamant can form, modulo $$$998\,244\,353$$$.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. of $$$n$$$ over all test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print one integer — the sum
