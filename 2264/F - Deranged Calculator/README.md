## Problem Statement

<div class="header"><div class="title">F. Deranged Calculator</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p><span class="tex-font-style-bf">Hacks are disabled on this problem.</span></p><p>We are excited to introduce a new language for this Codeforces round: the Deranged Calculator language (DC).</p><p>The DC language is a simplified programming language with some weird constraints. It only supports a single expression on one line and only has a single positive integer $$$n$$$ as input. The syntax of the expression is similar to that of most programming languages (in fact, the expression is valid Python), but it is very limited:</p><ul> <li> Expressions consist of the input parameter $$$n$$$, parenthesized expressions, and calls to the <span class="tex-font-style-tt">round</span> function. These are joined together by the operators <span class="tex-font-style-tt">+</span>, <span class="tex-font-style-tt">-</span>, <span class="tex-font-style-tt">*</span>, and <span class="tex-font-style-tt">/</span>. </li><li> Grouping with parentheses <span class="tex-font-style-tt">()</span> can be used to change the order of operations, as usual. </li><li> The operators <span class="tex-font-style-tt">*</span> and <span class="tex-font-style-tt">/</span> have equal precedence and take precedence over <span class="tex-font-style-tt">+</span> and <span class="tex-font-style-tt">-</span>, which also have equal precedence. Operators of equal precedence are evaluated from left to right. </li><li> The <span class="tex-font-style-tt">round</span> function takes a single expression as its argument and rounds its value to the nearest integer, rounding up when the fractional part is exactly $$$0.5$$$. (For example, <span class="tex-font-style-tt">round(n/(n-n-n-n))</span> will always evaluate to $$$0$$$, because $$$x/(x-x-x-x)=-\frac{1}{2}$$$ for a positive integer $$$x$$$. The fractional part is $$$0.5$$$, so it will be rounded up to $$$0$$$.) </li><li> Only the input value $$$n$$$ can be used; no numeric constants are allowed in the program. </li><li> All operations are performed using exact fractional arithmetic, so division does not round and can produce fractions. </li></ul><p>A <span class="tex-font-style-it">derangement</span> of $$$n$$$ numbers is a permutation of those numbers in which none of the numbers appears in its original position. For example, the derangements of the sequence $$$[1, 2, 3]$$$ are $$$[2, 3, 1]$$$ and $$$[3, 1, 2]$$$.</p><p>You are given a single integer $$$k$$$. Your job is to make a valid DC program that, for every integer $$$n$$$ ($$$2 \le n \le k$$$), calculates the number of derangements of the sequence $$$[1, 2, \ldots, n]$$$, when $$$n$$$ is given as input to the DC program. The length of the program should not exceed $$$10\,000$$$ characters.</p><p>A <span class="tex-font-style-bf">local testing tool</span> is provided to help you develop your solution. It can be found under Contest Materials.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The only line of input contains a single integer $$$k$$$ ($$$k \in \{2,3,50\}$$$).</p><p>Your DC program should output the correct number of derangements for all integers $$$n$$$ such that $$$2 \le n \le k$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>Output a valid DC expression on a single line. The expression should only consist of the characters <span class="tex-font-style-tt">round()+-*/</span> and the length of the expression should not exceed $$$10\,000$$$ characters.</p><p>Your expression will be run on all integers $$$n$$$ such that $$$2 \le n \le k$$$. For each such run, the DC expression should not divide by $$$0$$$ at any time, and its value must be the number of derangements of $$$n$$$.</p></div><div class="sample-tests"><div class="section-title">Examples</div><div class="sample-test"><div class="input"><div class="title">Input<div title="Copy" data-clipboard-target="#id0038332480370395483" id="id003591245633150776" class="input-output-copier">Copy</div></div><pre id="id0038332480370395483"><div class="test-example-line test-example-line-odd test-example-line-1">2</div></pre></div><div class="output"><div class="title">Output<div title="Copy" data-clipboard-target="#id004950206227328604" id="id008187654054353932" class="input-output-copier">Copy</div></div><pre id="id004950206227328604">n-n/n
