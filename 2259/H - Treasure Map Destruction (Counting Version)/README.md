It is guaranteed that Bessie buried treasure on at least one island.</p><p>In order to remember where she buried her treasure, she created a treasure map. Panicked, Bessie gives you the destroyed array $$$b$$$, and wants to know how many possible distinct sets of islands she could have placed her treasures on. Two sets $$$A, B$$$ are distinct if there exists at least one element in $$$A$$$ that is not in $$$B$$$ or vice versa. </p><p>It's possible that Bessie messed up while writing the treasure map, so there could be no possible set of islands on which she could have placed her treasure. </p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line of the input contains $$$t$$$ ($$$1 \leq t \leq 10^4$$$) — the number of test cases.</p><p>The first line of each test case contains $$$n$$$ ($$$1 \leq n \leq 2 \cdot 10^5$$$) — the number of islands.</p><p>The second line contains $$$b_1, b_2, \ldots, b_n$$$ ($$$-1 \leq b_i \leq n-1$$$) — the destroyed array of distances.
